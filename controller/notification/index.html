Notification 通知

悬浮出现在页面角落，用于系统级消息通知。默认从右上角出现，4.5 秒后自动关闭，支持标题 + 正文、多种类型和位置。

基础用法

通过 notification.show() 打开通知，需设置 title 和 message。

打开通知

不同类型

提供 primary、success、warning、info、error 五种类型。

Primary Success Warning Info Error

无标题 / 无类型

可以省略 title 或不设置 type（不显示图标）。

无标题 无类型图标

自定义时长

通过 duration 控制显示时长（毫秒），设为 0 则不自动关闭。

显示 10 秒 永不消失

代码主动关闭

notification.show() 返回实例，调用 close() 可主动关闭。 即使 duration: 0（不自动关闭），也可通过 inst.close() 手动关闭。

模拟异步任务（2 秒后关闭）

通知位置

通过 position 控制出现位置，支持： top-right（默认）、top-left、 bottom-right、bottom-left。

右上角 左上角 右下角 左下角

堆叠通知

同一位置的多个通知会自动堆叠，关闭后下方通知会上移。

连续弹出 3 条 关闭全部

点击回调

通过 onClick 设置点击通知时的回调。鼠标悬停时暂停自动关闭计时。

可点击通知
