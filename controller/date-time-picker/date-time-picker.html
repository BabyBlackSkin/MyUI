DateTimePicker 日期时间选择器

独立组件，内部拼 DatePickerPane + TimeSpinner。 支持 type="'datetime'"（默认）与 type="'datetimerange'"。 默认 format / value-format 均为 YYYY-MM-DD HH:mm:ss。 顶部日期 + 时间入口（二级下拉）；外层「确定」写入。Esc / 点外面：先关二级再关主面板。

基础用法

点输入框打开面板；顶部点时间框弹出二级时间面板（取消 / 确定）；选完后点底部「确定」写入。

值：{{ctrl.dt1}}
visible：{{ctrl.visible}}　lastChange：{{ctrl.lastChange}}　calendar：{{ctrl.lastCalendar}}

展示格式

format="'YYYY-MM-DD HH:mm'" 时时间列不出秒；写入 value-format 时秒补 00。

值：{{ctrl.dt2}}

箭头选择

arrow-control 为 true 时时间列使用上下箭头。

值：{{ctrl.dtArrow}}

禁用日期 / 时刻

disabled-date 透传 Pane； disabled-hours / disabled-minutes / disabled-seconds 透传 Spinner。 临时值非法时「确定」不可用；「此刻」落在禁用上不写入。

值：{{ctrl.dt4}}

快捷选项

点快捷项立刻写入并关层；值须为完整日期时间字符串（按 value-format）。

值：{{ctrl.dtShortcut}}

只读输入 / 禁用

editable=false

disabled

日期时间范围

type="'datetimerange'"：顶栏起止日期/时间铺满，双日历选范围；页脚仅「确定」（无「此刻」）。 ngModel 为 [start, end]；可选双向 start / end。

model：{{ctrl.range1}}　start：{{ctrl.rangeStart}}　end：{{ctrl.rangeEnd}}

范围默认值

值：{{ctrl.range2}}

范围快捷选项

快捷须返回长度 2 的完整日期时间数组，点后立刻写入并关层。

值：{{ctrl.rangeShortcut}}
