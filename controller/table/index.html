基础用法

带斑马纹表格

带边框表格

默认情况下，Table 组件是不具有竖直方向的边框的， 如果需要，可以使用 border 属性，把该属性设置为 true 即可启用。

带状态表格

可将表格内容 highlight 显示，方便区分「成功、信息、警告、危险」等内容。

可以通过指定 Table 组件的 row-class-name 属性来为 Table 中的某一行添加 class， 这样就可以自定义每一行的样式了。

多选表格

选择多行数据时使用 Checkbox。可通过 type="selection" 列开启多选，表头 checkbox 可全选/取消当前可见行。

已选中 {{getSelectedCount(selectedRows)}} 行

替换 data（新数组，清空选中） splice 删除首行（cleanSelection） 恢复 data

多选表格（无 row-key）

未设置 row-key 时，data 变化会按行对象引用清理无效选中。

已选中 {{getSelectedCount(noRowKeySelectedRows)}} 行

splice 删除首行

树形表格

当 row 含 children 字段时，可通过 tree-props 渲染树形表格。使用 type="expand" 单独作为展开列；若与多选同时使用，展开列在第一列，checkbox 在第二列。

树形多选可通过 group-selection 开启组内联动（默认 false）。设为 true 后：选中父节点时自动选中其所有后代子节点及同级兄弟节点；选中子节点/叶子节点时自动选中同级兄弟节点；取消选择与选中行为对称。

已选中 {{getTreeSelectedCount()}} 行

可展开行

通过 type="expand" 列展开行，type="extension" 定义展开区域自定义内容。展开行单独占一行并合并所有列，类似 Element Plus 的 expand 实现。

详情：{{$context.row.detail}}
