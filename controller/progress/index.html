Progress 进度条

用于展示操作进度，告知用户当前状态。

线形进度条

通过 percentage 设置进度比例，范围 0-1。可使用 format 自定义文字格式。

百分比内显

设置 text-inside 和 stroke-width 将百分比显示在进度条内部。

自定义颜色

color 支持颜色字符串、颜色数组或函数。

环形进度条

设置 type="circle" 使用环形进度条，width 控制大小。

仪表盘形进度条

设置 type="dashboard" 使用仪表盘形进度条。

不确定进度

设置 indeterminate 开启不确定进度，duration 控制动画时长。

加载扫光动画

进度处于加载中（0 < percentage < 1）时，进度条内会自动显示白色渐变扫光动画。可通过 animated 手动控制，duration 控制扫光速度。
