DatePickerPane 日期面板

面板形式的日期选择器（无输入框）。以「日」为基本单位，默认将选中值序列化为 YYYY-MM-DD HH:mm:ss（UTC 日历分量）。

基础用法

设置 type="'date'"，选择某一天。绑定值为当天 00:00:00 的字符串。

选中值：{{ctrl.dateValue}}

不同选择类型

通过 type 切换选择粒度： week / month / year。

week

{{ctrl.weekValue}}

month

{{ctrl.monthValue}}

year

{{ctrl.yearValue}}

多选

dates / months / years 支持多选，再次点击取消。 可用 max-select-limit 限制最多可选数量。

dates（最多 3 个）

{{ctrl.datesValue}}

months

{{ctrl.monthsValue}}

years

{{ctrl.yearsValue}}

禁用日期

通过 disabled-date 传入判断函数，返回 true 的日期不可选。 下例禁用今天之前的日期，并用 cell-class-name 给周末加样式。

选中值：{{ctrl.disabledDateValue}}

禁用状态

设置 disabled 后，整面板不可交互，已选高亮仍会显示。

API

Attributes

属性名 说明 类型 可选值 默认值
ng-model 绑定值。单选为字符串，多选 / week 为字符串数组 string / string[] / null — —
type 选择类型 string date / dates / week / month / months / year / years date
value-format 绑定值的格式（dayjs token） string — YYYY-MM-DD HH:mm:ss
disabled 是否禁用整面板 boolean — false
disabled-date 判断日期是否禁用，参数为 UTC Date Function — —
max-select-limit 多选时最多可选数量，达到后忽略新选 number — —
default-value 无选中值时面板打开的视图锚点，不写入 model string — —
show-week-number 是否显示周序号（仅 date / dates / week） boolean — true
cell-class-name 自定义单元格 class，参数为 UTC Date Function — —

Events

事件名 说明 回调参数
on-change / ng-change 选中值变化时触发（先更新 ngModel，再回调） (value, type)
on-panel-change 翻页或表头下钻时触发 (date, mode, view)
