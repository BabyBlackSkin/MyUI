TimePicker 时间选择器

输入框 + 弹层，内部复用 TimeSpinner。 ngModel 为纯时间字符串；默认 format / value-format 均为 HH:mm:ss。 面板内为临时选中，点「确定」写入；Esc / 点外面丢弃。

基础用法

点击输入框打开面板，选择后点「确定」。支持「此刻」、清空。

值：{{ctrl.time1}}
visible：{{ctrl.visible}}　lastChange：{{ctrl.lastChange}}

展示格式

format="'HH:mm'" 时面板只出时、分两列；写入 value-format 时秒补 00。

值：{{ctrl.time2}}

箭头选择

arrow-control 为 true 时使用上下箭头。

值：{{ctrl.timeArrow}}

禁用时刻

disabled-hours / disabled-minutes / disabled-seconds。 禁用项灰显；临时值非法时「确定」不可用；「此刻」落在禁用上不写入。

值：{{ctrl.time4}}

只读输入 / 禁用
