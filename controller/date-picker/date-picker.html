DatePicker 日期选择器

在 DatePickerPane 之上提供输入框与弹出层。值契约与 Pane 一致（civil date → UTC 字符串）， 默认 value-format 为 YYYY-MM-DD HH:mm:ss；输入框展示由 format 控制。

基础用法

以「日」为基本单位。输入框只读，点击打开面板，选完关闭。

API

Attributes

属性名 说明 类型 可选值 默认值
ng-model 绑定值 string / string[] / null — —
start / end 仅 range，与 ngModel 双向同步 string / null — —
type 选择类型 string date / dates / week / month / months / year / years / daterange / monthrange / yearrange date
value-format 绑定值格式（透传 Pane） string — YYYY-MM-DD HH:mm:ss
format 输入框展示格式 string — 按 type 不同
placeholder 占位文案 string — 请选择日期
disabled 禁用整控件 boolean — false
disabled-date 日期禁用函数，透传 Pane Function — —
clearable 是否可清空（禁用时不展示） boolean — true
shortcuts 快捷选项 Array<{text, value}> — —
default-value 无值时面板锚点，透传 Pane string — —
max-select-limit 多选上限 number — —
range-separator 范围分隔符 string — ~
size 输入框尺寸 string large / default / small —

Events

事件名 说明 回调参数
on-change / ng-change 值变化，先更新 ngModel (value, type)
on-visible-change 弹层打开 / 关闭 (visible)
on-panel-change 面板翻页 / 下钻（透传 Pane） (date, mode, view)
on-calendar-change 仅 range 选点过程 (dates)
on-focus / on-blur 聚焦 / 失焦 —
